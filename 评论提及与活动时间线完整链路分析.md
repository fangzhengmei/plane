## 二、通知生成与权限校验流程

### 2.1 评论创建的 API 权限校验

#### 接口权限装饰器
`apps/api/plane/app/permissions/base.py:13-87` 中 `allow_permission` 装饰器实现权限校验：

```python
class ROLE(Enum):
    ADMIN = 20
    MEMBER = 15
    GUEST = 5

def allow_permission(allowed_roles, level="PROJECT", creator=False, model=None):
    def decorator(view_func):
        @wraps(view_func)
        def _wrapped_view(instance, request, *args, **kwargs):
            # 1. 如果是 creator 模式，先校验是否是创建者
            if creator and model:
                obj = model.objects.filter(id=kwargs["pk"], created_by=request.user).exists()
                if obj: return view_func(...)
            
            # 2. 校验项目成员角色
            allowed_role_values = [role.value for role in allowed_roles]
            is_user_has_allowed_role = ProjectMember.objects.filter(
                member=request.user,
                project_id=kwargs["project_id"],
                role__in=allowed_role_values,
                is_active=True,
            ).exists()
            
            if is_user_has_allowed_role: return view_func(...)
            # 3. 工作区管理员特殊处理
            elif (ProjectMember.objects.filter(...).exists() 
                  and WorkspaceMember.objects.filter(..., role=ROLE.ADMIN.value).exists()):
                return view_func(...)
            
            return Response({"error": "权限不足"}, status=403)
    return decorator
```

```python
def extract_mentions(issue_instance):
    data = json.loads(issue_instance)
    html = data.get("description_html") or data.get("comment_html")
    soup = BeautifulSoup(html, "html.parser")
    mention_tags = soup.find_all("mention-component", attrs={"entity_name": "user_mention"})
    mentions = [tag["entity_identifier"] for tag in mention_tags]
    return list(set(mentions))  # 去重
```

```python
def get_new_mentions(requested_instance, current_instance):
    mentions_older = extract_mentions(current_instance)
    mentions_newer = extract_mentions(requested_instance)

def get_removed_mentions(requested_instance, current_instance):
    mentions_older = extract_mentions(current_instance)
    mentions_newer = extract_mentions(requested_instance)
```

```python
def process_mention(mention_component):
```

## 六、关键设计决策与技术要点

### 6.1 数据存储设计
- **HTML 优先存储**：保留完整的 `<mention-component>` 标签，便于二次解析
- **多格式冗余**：同时存储 HTML、JSON、纯文本三种格式，权衡查询效率与灵活性
- **关系独立化**：`IssueMention` 单独存储，便于按提及人筛选 Issue

### 6.2 异步任务设计
- **任务链解耦**：活动记录与通知生成分离，失败不影响主流程
- **批量操作**：使用 `bulk_create` 优化数据库写入
- **幂等性保障**：Redis 分布式锁防止重复邮件发送

### 6.3 权限模型
- **角色层级**：ADMIN(20) > MEMBER(15) > GUEST(5)，数值比较实现权限继承
- **双重校验**：接口层装饰器 + 业务层特殊校验（访客评论限制）
- **工作区管理员豁免**：工作区管理员默认拥有所有项目权限

### 6.4 前端优化
- **LocalStorage 持久化**：过滤器和排序状态本地存储，刷新不丢失
- **细粒度过滤**：支持按活动类型单独筛选，而非简单开关
- **增量加载**：API 支持 `created_at__gt` 参数实现增量拉取
